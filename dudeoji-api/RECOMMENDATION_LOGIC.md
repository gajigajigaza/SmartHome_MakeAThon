# 추천 판단 로직 정리 (`recommendation_engine.py`)

`determine_action()` / `_determine_action_core()` 기준 정리. 코드가 바뀌면 이 문서도 같이 업데이트할 것.

## 구조 요약

- `_determine_action_core()`가 action/summary/reason/popup을 결정한다.
- `determine_action()`은 그 결과의 `title` 필드를 `_resolve_title()`로 **항상 덮어쓴다.**
  - 즉 `_determine_action_core()` 안의 각 분기에 적힌 `"title": "..."` 리터럴은 실제 화면에는 나가지 않는 죽은 값이다.
  - 제목은 오직 `action` (+ ENJOY인 경우 `is_ac_on`/`window_is_open`)으로만 결정되며, 그 결과는 아래 8종 중 하나로 고정된다.

## 임계값 (`LOGIC_THRESHOLDS`)

| 항목 | 값 |
|---|---|
| 센서 이상 온도 범위 | -10℃ 미만 / 50℃ 초과 |
| 더움 기준 | 실내 26℃(기본값) 이상 또는 불쾌지수(THI) 75 이상 — 26℃는 `places.target_indoor_hot_temperature`로 장소별 오버라이드 가능(`determine_action(indoor_hot_threshold=...)`), 값이 없으면 이 기본값을 씀 |
| 추움 기준 | 실내 18℃ 미만 |
| 습함 기준 | 실내 습도 70% 이상 |
| 미세먼지 나쁨 | PM2.5 35㎍/㎥ 초과 |
| 환기 유효 풍속 | 3m/s 이상 (+ 실외온도 ≤ 실내온도+2℃) |
| 강풍(위험) 기준 | 10m/s 이상 |
| 에어컨 최소 유지시간 | 기본 30분 (실내온도 ≥22℃일 때만 적용) |

## 대표 멘트 8종 (`_TITLES` / `_resolve_title`)

| # | title | 결정 기준 |
|---|---|---|
| 1 | 에어컨 켤 타이밍이에요! | action = `USE_AIRCON` |
| 2 | 지금은 창문 열 타이밍이에요! | action = `OPEN_WINDOW` |
| 3 | 창문 닫을 타이밍이에요! | action = `CLOSE_WINDOW` |
| 4 | 에어컨이 켜져 있어요! 시원한 바람 즐기는 중 | action = `ENJOY` 이고 `is_ac_on == True` |
| 5 | 창문이 열려 있어요! 자연 바람 즐기는 중 | action = `ENJOY` 이고 ac는 아니고 `window_is_open == True` |
| 6 | 딱 좋은 상태 유지 중 | action = `ENJOY` 또는 `MAINTAIN` 이고 ac도 안 켜있고 창문도 안 열려 있음 |
| 7 | 에어컨 끌 타이밍이에요! | action = `TURN_OFF_AIRCON` (재실 없음 / 자연환기로 충분, 두 트리거를 하나의 액션·제목으로 통합) |
| 8 | 어라, 센서가 이상해요! | action = `ERROR` (온도 이상 또는 창문/에어컨 센서 미연결, 세 케이스 통합) |

> ENJOY의 3개 제목(④/⑤/⑥)은 통일 후보로 검토했으나 유지하기로 함 — 서로 다른 실제 기기 상태(에어컨 켜짐 / 창문 열림 / 둘 다 꺼짐)를 가리키는 정보라서, 하나로 합치면 제목만 보고 현재 상태를 파악하기 어려워짐.

**참고**
- `ENJOY` 액션은 실행 시점의 `is_ac_on`/`window_is_open`에 따라 title이 ④/⑤/⑥ 중 하나로 갈립니다(에어컨 상태 우선).
- `is_auto_triggered`/`show_popup`/`popup_message` 필드는 삭제됨(2026-07-30) — "서버가 AUTO 모드일 때만 확인 팝업을 띄운다"는 옛 설계(`RecommendationPopup.jsx`, 현재 미마운트)용이었는데, 지금 실제로 동작하는 `RecommendationCard.jsx`의 5초 카운트다운은 `current_mode`와 무관하게 실행 가능한 액션이면 전부 처리해서 이 필드들을 읽는 곳이 없었다. `current_mode`/`is_auto` 자체는 계속 쓰인다 — 에어컨 최소 가동시간 유지 분기(4번 규칙)가 자동 제어 켠 사용자에게만 적용되는 게이트로 남아 있음.

## title별 summary / reason 전체 (총 22개 조합)

### ① 에어컨 켤 타이밍이에요! (`USE_AIRCON`) — 3개

| summary | reason | 트리거 조건 |
|---|---|---|
| 창문을 열 수 없는 실외 환경입니다. 에어컨을 켤까요? | 실내가 {온도}도(불쾌지수 {THI})로 덥지만 실외 날씨/공기질이 좋지 않아 에어컨 사용을 권장 | 비·강풍·미세먼지 나쁨 + 창문 닫힘 + 더움 + 에어컨 꺼짐 |
| 실내 습도가 높아요. 에어컨을 켤까요? | 실내 습도가 {습도}%로 높음. 제습+냉방 위해 에어컨 권장 | 실외 정상 + 더움 + 습도≥70% + 에어컨 꺼짐 |
| 바람이 약하고 실외도 더워요. 에어컨을 켤까요? | 실내 {온도}도(THI {값}), 실외 {온도}도로 모두 높고 풍속도 {값}m/s로 약함 → 에어컨이 확실한 방법 | 실외 정상 + 더움 + 안 습함 + 바람 도움 안 됨 + 실외가 안 시원함 + 에어컨 꺼짐 |

### ② 지금은 창문 열 타이밍이에요! (`OPEN_WINDOW`) — 2개

| summary | reason | 트리거 조건 |
|---|---|---|
| 시원한 바람이 불어 자연 환기가 유리해요. | 풍속 {값}m/s이고 실외 온도가 환기 가능한 범위 | 더움 + 안 습함 + 바람 도움됨(≥3m/s, 실외≤실내+2℃) + 창문 닫힘 + **에어컨 꺼짐** |
| 실외 공기가 더 시원해 자연 환기가 유리해요. | 실외({온도}도)가 실내({온도}도)보다 시원함 | 더움 + 안 습함 + 바람 도움 안 됨 + 실외가 더 시원함 + 창문 닫힘 + **에어컨 꺼짐** |

> jh 수정함 - 두 경우 다 에어컨이 켜져 있으면 ⑦(에어컨 끌 타이밍)이 먼저 뜨고, 다음 reading에서 에어컨이 꺼진 게 확인되면 그제서야 이 ②가 뜬다(아래 ⑦ 참고). "창문 여세요"만 던지고 이미 켜진 에어컨을 언급 안 하는 모순을 없애기 위함.

### ③ 창문 닫을 타이밍이에요! (`CLOSE_WINDOW`) — 3개

| summary | reason | 트리거 조건 |
|---|---|---|
| 지금 밖에 비가 오거나 공기가 좋지 않아요. | (비/눈 · 강풍 · 미세먼지 중 실제 해당 사유) + "창문을 닫아주세요" | 비·강풍·미세먼지 나쁨 + 창문 열림 |
| 에어컨이 켜진 채 창문이 열려 있어요. | 실내 {온도}도(THI {값})로 덥고, (습도도 높거나 / 풍속 약하고 실외도 안 시원함) → 자연바람만으론 부족, 냉방 공기 낭비 중 | 에어컨 켜짐 + 창문 열림 + 자연환기 불충분 |
| 실내가 쌀쌀해요. 창문을 닫을까요? | 실내 온도가 {온도}도로 낮아 창문을 닫아주세요 | 안 더움 + 실내<18℃ + 창문 열림 |

### ④ 에어컨이 켜져 있어요! 시원한 바람 즐기는 중 (`ENJOY`, 에어컨 켜짐) — 4개

| summary | reason | 트리거 조건 |
|---|---|---|
| 안전하고 시원하게 온도를 조절하고 있어요. | 실내가 아직 {온도}도로 더워 에어컨으로 온도를 낮추는 중, 실외 환경이 나빠 창문 대신 에어컨 유지 | 비·강풍·미세먼지 나쁨 + 창문 닫힘 + 더움 + 에어컨 켜짐 |
| 에어컨 가동 {N}분 차, 목표 시간({M}분)까지 유지하고 있어요. | 에어컨은 일정 시간 유지가 효율적 — 최소 가동시간 동안 유지 | 에어컨 켜짐 + 창문 닫힘 + 가동시간<목표유지시간(기본 30분) + 실내≥22℃ |
| 높은 습도를 에어컨으로 조절하고 있어요. | 실내 습도가 {값}%로 높음. 에어컨 유지 | 더움 + 습도≥70% + 에어컨 켜짐 |
| 에어컨으로 더위를 식히고 있어요. | 풍속 {값}m/s로 약하고 실외도 {값}도로 더워 자연환기 기대 어려움 → 유지 적합 | 더움 + 안 습함 + 바람 도움 안 됨 + 실외 안 시원함 + 에어컨 켜짐 |

### ⑤ 창문이 열려 있어요! 자연 바람 즐기는 중 (`ENJOY`, 창문 열림) — 2개

| summary | reason | 트리거 조건 |
